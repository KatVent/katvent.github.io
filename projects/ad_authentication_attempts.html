Suspicious Active Directory Authentication Attempts

Summary

The activity was generated intentionally as part a controlled cybersecurity exercise.
Multiple failed authentication attempts where detected against an Active Directory user account. The authentication attempts originated from a Kali Linux machine and resulted in the account being locked out.

Detection

Detection Rule

Multiple Failed Windows Authentication

Detection Condition

- Checks for Event ID : 4625 (Failed Logon)
- More than 4 failed attempts within 5 minutes.
- Target account identified
- Source IP identified

Environment

Attacker Machine:Kali Linux
Domain Controller:Windows Server 2025
SIEM:ELK Stack 8.11
Log Collector:WinlogBeat
Network:Lab Environment
Account:labuser1

Security Configuration - Account Lockout Policy

An Active Directory account lockout policy was configured to simulate a real-world defensive control against repeated authentication failures.
The policy was configured to:
- Account lockout threshold: 5 invalid login attempts
- Account lockout duration: 5 minutes
- Reset account lockout counter after: 5 minutes
The policy was applied to the ;ab environmentbefore conducting the authentication test.

Investigation

The SIEM logs were reviewed to determine the target and the source of the authentication attempts. Event ID 4625 confirmed that authentication attempts failed. The events were correlated with Event ID 4740, which confirmed that the targeted account was subsequently locked out. The `CallerComputerName` field in Event ID 4740 identified Kali as the computer associated with the lockout-causing authentication attempts.
