Cybersecurity Home Lab & SIEM

A cybersecurity home lab, built to practice log collection, monitoring, and threat detection against an Active Directory Domain. The lab runs on three physical hosts, network-isolated from home network, so traffic stays to the lab segment.

Tech Stack

SIEM/Log Analysis: ELK Stack (Elasticsearch, Logstash, Kibana) in Docker
Log Shipping: Winlogbeat
Identity: Active Directory Domain Services, Windows Server 2025
Endpoints: Windows 10 (x2)
Virtualization: VirtualBox(bridged networking)
Networking: Segmented subnets (192.168.10.0/24 for lab, 192.168.1.0/24 for home)

Architecture

The lab sits on its own subnet (192.168.10.0/24), seperated from the home network (192.168.1.0/24). One physical host runs the ELK Stack in Docker as the central log store and dashboard layer. The second host runs VirtualBox, hosting a Windows Server 2025 VM configured as an Active Directory domain controller, alongside Client02(Windows 10) VM joined to the domain. A third physical host also runs VirtualBox, hosting Client01(Windows 10), also domain-joined, giving two independent endpoints to generate and compare activity from. VirtualBox's networking is configured (bridged, so the VMs get real addresses on the 192.168.10.0/24 lab subnet) so each VM behaves like a distinct machine.

Log pipeline

Each Windows machine - the domain controller and both clients - runs Winlogbeat, shipping Security, System, and Application eventt logs to the ELK host. From there, Elasticsearch indexes the events and Kibana provides the interface used to investigate activity across the domain.
