Hashly - CLI Tool

A simple Python CLI tool to hash text or files using different algorithms. Built with argparse. The purpose of this project wasn't only to complete a specific action, but also to learn how a CLI-tool is been developed.

With hashly, we can hash text and files via the terminal using the following algorithms:

Blake2b Blake2s MD5 SHA1
SHA224 SHA256 SHA384 SHA3_224
SHA3_256 SHA3_384 SHA3_512 SHA512
SHAKE_128 SHAKE_256

How To Install

For the installation, we need Python 3.10 or newer. After that, we can install this in a virtual environment or install it globally.

Option 1: Run inside a virtual environment

Create virtual environment

git clone https://github.com/KatVent/hashly.git cd hashly python -m venv .venv

Activate virtual environment based on the OS
source .venv/bin/activate # For macOS / Linux .venv\Scripts\Activate.ps1 # For Windows (Powershell)
Install the package
pip install .

Option 2: Install globally

pip install pipx # if not installed pipx install hashly

Usage

Usage: hashly [command] (input) --alg [choice]

Command: string Choose string to hash file Choose file or path to hash

Choice: blake2b, blake2s, md5, sha1, sha224, sha256, sha384, sha3_224, sha3_256, sha3_384, sha3_512, sha512, shake_128, shake_256

Examples: hashly string "Hello World" --alg md5 hashly file file.txt --alg sha1
